# 🎵 Muxic.fy

A sleek, Spotify-inspired music player web app built to deliver a smooth and aesthetic music browsing experience.

🔗 **Live Demo:** [muxic-fy-by-dpnshuu.vercel.app](https://muxic-fy-by-dpnshuu.vercel.app/)

---

## ✨ Features

- 🎧 **Liked Songs Playlist** — A curated collection of handpicked Bollywood & international tracks
- 🖼️ **Album Art Display** — Beautiful cover images for every song
- ▶️ **Music Player UI** — Clean player interface inspired by Spotify
- 📱 **Responsive Design** — Works smoothly across devices
- 🌐 **Deployed on Vercel** — Fast and always online

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/your-username/muxic-fy.git

# Open in browser
cd muxic-fy
open index.html
```

Or just visit the [live site](https://muxic-fy-by-dpnshuu.vercel.app/) directly!
